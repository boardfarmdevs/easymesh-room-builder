# The room builder's documents

[Repository](../README.md) · [Site](https://vcpe.dev/easymesh-room-builder/)

The [site](https://vcpe.dev/easymesh-room-builder/) is the builder itself, running in the
browser. Its in-app manual (`roombuilder/static/manual.html`, the **Manual** button)
covers using it. These documents go further:

| Document | Kind | What it covers |
| --- | --- | --- |
| [Serving the builder](guides/serving.md) | guide | on the network, and as a static site with no server (Pyodide) |
| [Command line and HTTP API](reference/command-line-and-api.md) | reference | every command and every endpoint |
| [Parity with the configurator](reference/parity.md) | reference | the ported compiler, the byte parity with easymesh-medium's configurator, the tests |
